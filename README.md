# 体育祭しおりサイト 情報の入れ方ガイド

公開URL: https://kuro-83.github.io/sports-festival-2026/

しおりの中身(名前・時刻・競技・場所など)は、**`js/content.js` の1ファイルだけ**に書く。
ページはそこから自動で組み立てられるので、`index.html`・`css/`・`js/main.js` は触らなくていい。

---

## 1. 情報が来たら、ここを書き換える

`js/content.js` を開くと、上から順にページの並びと同じ順で項目が並んでいる。
各項目の上に「何を書くところか」「空にするとどうなるか」のコメントがある。

| 届いた情報 | 書き換える場所 |
| --- | --- |
| 体育祭の名前・スローガン・会場 | `site` の `name` / `slogan` / `venue`(名前は `index.html` の OGP にも。下の「共有時のプレビュー」) |
| 開催日 | `site.date`(`'2026-11-27'` の形) |
| 施設・場所の一覧 | `places.list` |
| タイムテーブル | `timetable.program`(時刻と名前)、`timetable.start` / `end` |
| 競技のルール・みどころ | `events`(挿絵はなし。文字だけ) |
| 他の班からの企画情報 | `others` |
| 間違い探しの説明・答え | `fun.spotText`、`fun.spotAnswerImage`(下の「おたのしみ」) |
| 隠れキャラの場所・セリフ | `hiddenChars`、`hiddenCharsText`、`hiddenCharsDone` |
| 注意事項 | `notices`(空 `[]` にすると注意事項のセクションごと消える) |

### 書き方のルール
- 文字は `'...'` で囲む
- 途中で改行したい時は `\n` を書く(例: `'1行目\n2行目'`)
- 件数は自由。1件ぶんの `{ ... },` をコピーすれば増やせる。消せば減る
- 配列を空 `[]` にすると、そのセクションごと消える。目次の番号(01〜)は自動で振り直される
  - 例: `others: []` にすると「ほかの企画」が消えて、「おたのしみ」が04になる

```js
// 例: 競技を1つ埋めたところ
{
  name: '大縄跳び',
  rule: 'クラス全員で3分間に何回跳べるか競う',
  highlight: '最後の30秒の追い上げ！\n掛け声にも注目',
},
```

### おたのしみ(隠れキャラ探し・間違い探し)

2つとも空にすると、おたのしみのセクションごと消えて、目次の番号が詰まる。

**間違い探し** … `fun`
- 問題は紙のしおりに載っていて、サイトには答えだけ載せる
- `spotText`: 見出しの下の1行の説明(例: しおりの裏表紙の間違い探し、答えはここ！)
- `spotAnswerImage`: 答えの画像。「答えを見る」を押すまで出ない(もう一度押すと隠れる)
- 説明も画像も空なら、間違い探しの欄ごと消える

**隠れキャラ探し** … `hiddenChars`、`hiddenCharsText`、`hiddenCharsDone`
- イラストの枠や、各セクションの大きい緑の番号(01〜06)の後ろにキャラが隠れて、ふちから顔だけ出している。タップすると出てきてセリフを言い、数秒で戻る
  - 番号に隠れる時は、数字の上のふちから頭の上半分が見える。目次(CONTENTS)やメニューの小さい番号には隠れない
- 場所は2通り。`hiddenCharsRandom` で切り替える
  - `true`(今の設定):開くたびに、`hiddenCharFrames` の枠からランダムに選ぶ。1つの枠(番号)に1体だけ、向きは上、位置(はし寄り・真ん中)もランダム(番号はいつも真ん中)。下の `frame` / `side` / `pos` は使わない
  - `false`:各キャラの `frame` / `side` / `pos` の決まった場所に隠れる
- `hiddenCharFrames`:ランダムの時に隠れてよい枠の候補。`'cover'`(表紙イラスト) / `'map'`(簡易マップ) / `'nums'`(セクション番号ぜんぶ)。番号を1つずつ選ぶ時は `'num-2'` のように書く。初期値は `['cover', 'map', 'nums']`
  - 消えているセクションの番号は候補に入らない(例:`others: []` なら番号は01〜05の5つ)
  - 候補の枠がキャラの数より少ない時は、出せる数だけ出る(`?check` に出る)。間違い探しの答えの画像には隠れない
- 1体ごとに `{ frame, side, pos, image, line }`(`frame` / `side` / `pos` は固定の時だけ使う)
  - `frame`: 隠れる枠。`'cover'` 表紙イラスト / `'map'` 簡易マップ / `'num-1'` セクション番号の01(`'num-3'` は03…。番号は表示されているセクションで振り直された後の数字)
  - 番号(`'num-…'`)の時は `side` / `pos` は使わず、いつも数字の上の真ん中から顔を出す
  - `side`: 顔を出す向き。`'top'` 枠の上 / `'left'` 枠の左 / `'right'` 枠の右
  - `pos`: ふちのどのあたりか。`'start'`(上か左のはし寄り) / `'center'`(真ん中) / `'end'`(下か右のはし寄り)
  - `image`: キャラの画像(空なら点線の丸)、`line`: タップした時のセリフ(短めに)
- 体数は自由。おたのしみに「●●○ 2 / 3」のように出る
- `hiddenCharsText`: 見出しの下の1行の説明、`hiddenCharsDone`: 全部見つけた時に出る緑の1行(紙吹雪も出る)
- `hiddenChars: []` にすると、隠れキャラも隠れキャラ探しの欄も出なくなる
- 見つけた状態は見た人のブラウザに「何体目か」で保存される(ランダムで場所が変わっても、見つけたキャラには✓がつく)。並び順を変えると保存した状態がずれるので、公開後は後ろに足すだけにするのがおすすめ
- 隠れる枠が無い時(セクションが5つしかないのに `'num-6'` など)や、枠のセクションが空で消えている時は、そのキャラは出ない(`?check` に出る)

### 共有時のプレビュー(OGP)とアイコン

LINEやSNSでURLを送った時のタイトル・説明・画像は、`content.js` ではなく **`index.html` の先頭(`<head>`)に直接書いてある**(LINEなどはJSを動かさずにHTMLだけ読むため)。

**体育祭の名前が決まったら**
1. `js/content.js` の `site.name` を書き換える(いつも通り)
2. `index.html` を開き、`og:title` の `content` を書き換える
   - 例: `<meta property="og:title" content="SPORTS DAY 2026 しおり">` → `content="第○回 ○○体育祭 しおり"`
   - 説明を変えたい時は `og:description` も
3. `?check` を付けて開き、「OGPのタイトルに体育祭の名前が入っていない」が出ていなければOK

**画像を差し替える時**
- 共有時の画像: `img/ogp.png` を同じ名前で上書きする(**1200×630px**、PNG、300KB以下がおすすめ。文字はスマホで小さく出ても読める大きさに)
  - 今のは仮の画像。作り方(元のHTML)は手元の `reference/ogp/` にある(公開はしない)
- アイコン: `favicon.svg`(タブのアイコン)、`favicon-32.png`(32×32、SVGが使えないブラウザ用)、`apple-touch-icon.png`(180×180、iPhoneのホーム画面用)を同じ名前で上書きする
- LINEはプレビューを長め(数日〜)覚えているので、先にURLを送っていた場合は、差し替えてもすぐには変わらないことがある

## 2. 画像の入れ方

1. 画像ファイルを `img/` フォルダに入れる(ファイル名は半角英数字がおすすめ。例: `cover.png`)
2. `js/content.js` の該当する `src` にパスを書く: `{ src: 'img/cover.png', alt: '表紙のイラスト' }`
3. `alt` は画像が見えない人向けの説明。飾りだけなら `''` のままでいい

`src` が `''` (空)の間は、斜線の仮の枠が表示される。

| 画像 | 場所 |
| --- | --- |
| 表紙イラスト | `site.coverImage` |
| 簡易マップ | `places.mapImage` |
| 走るキャラ | `timetable.runnerImage`(正方形がおすすめ。丸く切り取られる) |
| 間違い探しの答え | `fun.spotAnswerImage`(横幅いっぱいに、縦横の比率はそのままで出る) |
| 隠れキャラ | `hiddenChars` の各 `image`(正方形、背景が透明のPNGがおすすめ。44pxで出る。頭が上になる向きで描く) |

## 3. 確認のしかた

URLの最後に付けて開く。

| 付けるもの | 何が起きるか |
| --- | --- |
| `?check` | ページの一番上に「まだ［］のまま残っている項目」と「画像が未設定の場所」の一覧が出る。全部0件になれば入れ忘れなし |
| `?time=10:30` | 11/27の10:30として表示される。「いまここ」のキャラとNOW表示の確認用 |
| `?time=10:30&check` | 両方いっしょに使う |

例: `https://kuro-83.github.io/sports-festival-2026/?check`

どちらも付けない普段の表示には影響しない。

### 手元で見る時
`index.html` をブラウザで直接開けばだいたい見られる。うまく動かない時はサーバーを立てる:

```
python3 -m http.server 8000
```

→ http://localhost:8000/?check

## 4. 公開する

書き換えたら commit して push するだけ。1分前後で公開URLに反映される。

```
git add -A
git commit -m "競技の情報を入れた"
git push
```

GitHub Desktop を使う場合は、変更を確認して Commit → Push origin。

## ファイル構成
- `js/content.js` … **しおりの中身。ここだけ書き換える**
- `img/` … 画像を置く場所(`img/ogp.png` は共有時のプレビュー画像)
- `favicon.svg`・`favicon-32.png`・`apple-touch-icon.png` … ブラウザのタブ・ホーム画面のアイコン
- `index.html` … ページの枠
- `css/style.css` … 見た目。色・フォント・線は先頭の `:root` にまとめてある
- `js/main.js` … ページを組み立てる処理、「いまここ」、隠れキャラ、間違い探しの答え、ハンバーガーメニュー、入れ忘れチェック
