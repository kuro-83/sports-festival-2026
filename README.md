# 体育祭しおりサイト(11/27)

リストバンドのQRからスマホで見る、体育祭のしおり。HTML/CSS/JSだけ(ビルドなし)で、GitHub Pagesにそのまま置ける。

## ファイル
- `index.html` … ページ本体(表紙〜06注意事項まで1ページ)
- `css/style.css` … 見た目。色とフォントは先頭の `:root` にまとめてある
- `js/main.js` … タイムテーブルの「いまここ」と応援ボタン

## よく触るところ
- **プログラムの時刻と名前**: `js/main.js` の `PROGRAM`(と `DAY_START` / `DAY_END`)
- **イラスト**: 斜線の枠(`class="ph"`)の中身を `<img src="img/xxx.png" alt="…">` に置き換える。枠いっぱいに表示される
- **走るキャラ**: `id="runner"` の中身を `<img>` に置き換える

## 「いまここ」の動作確認
URLの末尾に `?time=10:30` を付けると、11/27のその時刻として表示される。

ローカルで見る時はサーバーを立てる(ファイルを直接開いてもJSは動くけど、念のため):

```
python3 -m http.server 8000
```
