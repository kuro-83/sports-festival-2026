# 体育祭しおりサイト 情報の入れ方ガイド

公開URL: https://kuro-83.github.io/sports-festival-2026/

しおりの中身(名前・時刻・競技・場所など)は、**`js/content.js` の1ファイルだけ**に書く。
ページはそこから自動で組み立てられるので、`index.html`・`css/`・`js/main.js` は触らなくていい。

---

## 1. 情報が来たら、ここを書き換える

`js/content.js` を開くと、上から順にページの並びと同じ順で項目が並んでいる。
各項目の上に「何を書くところか」「空にするとどうなるか」のコメントがある。

| 届いた情報 | 書き換える場所 |
| --- | --- |
| 体育祭の名前・スローガン・会場 | `site` の `name` / `slogan` / `venue` |
| 開催日 | `site.date`(`'2026-11-27'` の形) |
| 施設・場所の一覧 | `places.list` |
| タイムテーブル | `timetable.program`(時刻と名前)、`timetable.start` / `end` |
| 競技のルール・みどころ | `events` |
| 他の班からの企画情報 | `others` |
| 間違い探しの説明 | `fun.spotText` |
| 応援ボタンのキャラのセリフ | `cheer.lines`(下の「おたのしみの遊び」) |
| 隠れキャラの場所・セリフ | `hiddenChars`、`hiddenCharsDone` |
| 紙のしおりの謎の答え | `puzzles`、`puzzleWrong` |
| 注意事項 | `notices`(空 `[]` にすると注意事項のセクションごと消える) |

### 書き方のルール
- 文字は `'...'` で囲む
- 途中で改行したい時は `\n` を書く(例: `'1行目\n2行目'`)
- 件数は自由。1件ぶんの `{ ... },` をコピーすれば増やせる。消せば減る
- 配列を空 `[]` にすると、そのセクションごと消える。目次の番号(01〜)は自動で振り直される
  - 例: `others: []` にすると「ほかの企画」が消えて、「おたのしみ」が04になる

```js
// 例: 競技を1つ埋めたところ
{
  name: '大縄跳び',
  rule: 'クラス全員で3分間に何回跳べるか競う',
  highlight: '最後の30秒の追い上げ！\n掛け声にも注目',
  image: { src: 'img/oonawa.png', alt: '大縄跳びをする生徒のイラスト' },
},
```

### おたのしみの遊び(応援キャラ・隠れキャラ・謎解き)

**応援ボタンのキャラ** … `cheer`
- `charImage`: ボタンの横(スマホでは上)にいるキャラの画像。押すたびにぴょんと跳ねる
- `lines`: 押した回数ごとのセリフ。`from` = 何回目から、`line` = セリフ。行はいくつでも増やせる
- 押した回数はこれまで通り保存しない

```js
lines: [
  { from: 0, line: '応援してね！' },     // 押す前
  { from: 1, line: 'ありがとう！' },     // 1〜9回
  { from: 10, line: 'もっともっと！' },  // 10〜29回
],
```

**隠れキャラ探し** … `hiddenChars`、`hiddenCharsDone`
- 1体ごとに `{ section, where, image, line }`
  - `section`: 置くセクション。`'map'` 施設案内 / `'timetable'` タイムテーブル / `'events'` 競技説明 / `'others'` ほかの企画 / `'fun'` おたのしみ / `'notice'` 注意事項
  - `where`: `'head'` = 見出しの右はし、`'bottom'` = セクションの一番下の右はし(区切り線の上)
  - `image`: キャラの画像(空なら点線の丸)、`line`: タップした時の吹き出しのセリフ
- 体数は自由。「おたのしみ」に「隠れキャラ 1 / 3 見つけた」と出る
- `hiddenCharsDone`: 全部見つけた時に「おたのしみ」に出る特別メッセージ(紙吹雪も出る)
- `hiddenChars: []` にすると、隠れキャラも見つけた数も出なくなる
- 見つけた状態は見た人のブラウザに保存される。並び順を変えると保存した状態がずれるので、公開後は後ろに足すだけにするのがおすすめ
- 置き場所のセクションが空で消えていると、そのキャラは出ない(`?check` に出る)

**謎解きの答え合わせ** … `puzzles`、`puzzleWrong`
- 1問ごとに `{ title, note, answers, correct, hint, explain }`
  - `title`: 謎のタイトル、`note`: 問題の補足(例: しおりの裏表紙の謎。空なら出ない)
  - `answers`: 正解。表記ゆれは全部書く(例: `['たいいくさい', '体育祭']`)
    - 空白・全角半角・ひらがなとカタカナ・大文字小文字の違いは、書かなくても同じとみなす
    - 「答えを見る」では1つ目が出る
  - `correct`: 正解した時のメッセージ、`hint`: ヒント(空ならボタンが出ない)、`explain`: 解説(空なら出ない)
- `puzzleWrong`: 答えがちがった時の一言
- `puzzles: []` にすると出なくなる。正解した状態は見た人のブラウザに保存される

## 2. 画像の入れ方

1. 画像ファイルを `img/` フォルダに入れる(ファイル名は半角英数字がおすすめ。例: `cover.png`)
2. `js/content.js` の該当する `src` にパスを書く: `{ src: 'img/cover.png', alt: '表紙のイラスト' }`
3. `alt` は画像が見えない人向けの説明。飾りだけなら `''` のままでいい

`src` が `''` (空)の間は、斜線の仮の枠が表示される。

| 画像 | 場所 |
| --- | --- |
| 表紙イラスト | `site.coverImage` |
| 簡易マップ | `places.mapImage` |
| 走るキャラ | `timetable.runnerImage`(正方形がおすすめ。丸く切り取られる) |
| 競技の挿絵 | `events` の各 `image` |
| 間違い探しA・B | `fun.spotImages` の1つ目・2つ目 |
| 応援ボタンのキャラ | `cheer.charImage`(正方形がおすすめ) |
| 隠れキャラ | `hiddenChars` の各 `image`(正方形、背景が透明のPNGがおすすめ。40pxくらいで出る) |

## 3. 確認のしかた

URLの最後に付けて開く。

| 付けるもの | 何が起きるか |
| --- | --- |
| `?check` | ページの一番上に「まだ［］のまま残っている項目」と「画像が未設定の場所」の一覧が出る。全部0件になれば入れ忘れなし |
| `?time=10:30` | 11/27の10:30として表示される。「いまここ」のキャラとNOW表示の確認用 |
| `?time=10:30&check` | 両方いっしょに使う |

例: `https://kuro-83.github.io/sports-festival-2026/?check`

どちらも付けない普段の表示には影響しない。

### 手元で見る時
`index.html` をブラウザで直接開けばだいたい見られる。うまく動かない時はサーバーを立てる:

```
python3 -m http.server 8000
```

→ http://localhost:8000/?check

## 4. 公開する

書き換えたら commit して push するだけ。1分前後で公開URLに反映される。

```
git add -A
git commit -m "競技の情報を入れた"
git push
```

GitHub Desktop を使う場合は、変更を確認して Commit → Push origin。

## ファイル構成
- `js/content.js` … **しおりの中身。ここだけ書き換える**
- `img/` … 画像を置く場所
- `index.html` … ページの枠
- `css/style.css` … 見た目。色・フォント・線は先頭の `:root` にまとめてある
- `js/main.js` … ページを組み立てる処理、「いまここ」、応援ボタン、隠れキャラ、謎解き、ハンバーガーメニュー、入れ忘れチェック
