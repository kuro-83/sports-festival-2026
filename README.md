### 書き方のルール
- 文字は `'...'` で囲む
- 途中で改行したい時は `\n` を書く(例: `'1行目\n2行目'`)
  - 競技説明(ひとこと・ルール・見どころ・Q&A)・応援コール・スローガンの一文・注意事項の文は、**自動で文節の切れ目で折り返す**(BudouX。下の「日本語の折り返し」)。紙面の幅に合わせた `\n` は入れない。`\n` は意味のある改行(リストなど)だけ
- 件数は自由。1件ぶんの `{ ... },` をコピーすれば増やせる。消せば減る
- 配列を空 `[]` にすると、そのセクションごと消える。目次の番号(01〜)は自動で振り直される
  - 例: `others: []`(今の設定)で「ほかの企画」が消えて、「おたのしみ」が04、「注意事項」が05になっている

### タイムテーブル … `timetable.program`
- 1行ずつ `{ start: '10:00', end: '10:30', label: '生徒入室' }`。時刻の早い順に並べる
- 表示は「10:00〜10:30」。今の時刻が start〜end の間の行に「NOW」がつく
- どの行にも入らない時間(すき間)は「次は〇〇(12:20から)」、最初の行より前は「まだ始まってないよ」と出る
- キャラが走るのは、最初の行の start 〜 最後の行の end。最後の行の end を過ぎると「おつかれさま」
- `end` を空にした行は、次の行の start までとして扱う(最後の行は `end` を必ず書く)
- ここには**予定の時刻**を書く。当日の遅れは上の「0. 当日の時間調整」(`DELAY_MIN`)で調整する

### 競技説明 … `events`
最初は「時刻・ガチ/ゆる・競技名」の一覧だけが出て、タップするとその競技の説明が開く(もう一度タップで閉じる)。上から順(タイムテーブルの順)に並ぶ。1競技ごとの項目:

| 項目 | 中身 | 空の時 |
| --- | --- | --- |
| `name` | 競技名。**タイムテーブルの `label` と1文字も違えずにそろえる**(時刻とリンクのため) | — |
| `timetableName` | タイムテーブルでは名前が違う時だけ、タイムテーブルの `label` を書く(例:`name: 'キャンパス対抗リレー'`、`timetableName: 'CP対抗リレー'`)。書かなければ `name` で探す | `name` で探す |
| `campus` | 担当キャンパスの色。`'green'` / `'yellow'` / `'pink'`(下の `campusColors`)。時刻・小さい四角・ルールの番号・Q&Aの「A」・見どころのマーカーの色になる | サイトの緑 |
| `category` | `'gachi'`(ガチ競技) か `'yuru'`(ゆる競技)。競技名の上に小さいグレーの文字で出る | 出ない |
| `summary` | ひとことで言うとどんな競技か(1〜2文)。「ABOUT」の下の1行目に太字で出る | 出ない |
| `rules` | ルールの箇条書き `['1つめ', '2つめ']`。`summary` の下に「— 〇〇」の1列で出る | 出ない |
| `rulesNumbered` | `true` でルールが「1 けんけん」のような番号つきの2列になる(サイコロの目など) | 「—」の1列 |
| `highlight` | 見どころ。「HIGHLIGHT」の下に太字で、文字の下半分にキャンパスの色のマーカー。2行以上は `['1行目', '2行目']`(`'1行目\n2行目'` でもいい)。マーカーは行ごと | 出ない |
| `qa` | Q&A `[{ q: '質問', a: '答え' }]`。「Q」「A」がついて、少し小さめの文字で出る。答えにリストも入れる時は `a: { text: '文', list: ['1つめ', '2つめ'], numbered: true }`(リスト → 文の順。`numbered: true` でルールと同じ番号つき2列。例:ドッヂビーのルーレット) | 出ない |

- **時刻はタイムテーブルから自動で入る**(`events` には書かない)。`timetable.program` に同じ名前(`timetableName` があればそれ)の行がない競技は時刻の欄が空になり、`?check` に「タイムテーブルに同じ名前がない競技」として出る
- タイムテーブルの、競技説明に同じ名前(`timetableName` を含む)がある行は、タップするとその競技まで飛んで開く(右端に「→」)。URLの最後に `#event-競技名`(例:`#event-サイコロ運試しリレー`)を付けて開いても、その競技が開いた状態で出る
- `summary`・`rules`・`highlight`・`qa` が全部空の競技は、開いた時に `eventsEmptyText`(今は「くわしい説明は準備中！当日をお楽しみに」)だけが出る。`?check` に「説明が空の競技」として出る

**キャンパスの色** … `campusColors`
- `color`(小さい四角の色)、`ink`(時刻・番号・「A」の文字の色。白地で読める濃さにする)、`marker`(見どころのマーカーの薄い色)
- キャンパスの名前はサイトには出ない。色を変えたい時はここだけ書き換える。`campus` の値がここに無い時は `?check` に出る

```js
// 例: 競技を1つ埋めたところ
{
  name: '大縄跳び',
  campus: 'green',
  category: 'gachi',
  summary: 'クラス全員で3分間に何回跳べるか競う！',
  rules: ['1クラス全員で跳ぶ', '引っかかったら0から数え直し'],
  rulesNumbered: false,
  highlight: ['最後の30秒の追い上げ！', '掛け声にも注目'],
  qa: [
    { q: '途中で抜けてもいい？', a: 'けがをした時はOK！' },
  ],
},
```

### 応援コール＆スローガン … `cheer`(+ `site.slogan`・`site.sloganImage`)
競技説明の次のセクション。コール → 応援歌の1行 → スローガンの順に出る。`calls`・`song`・`goods` とスローガンが全部空だと、セクションごと消えて目次の番号が詰まる(それぞれ空なら、その欄だけ消える)。各コール名の下の線と、スローガンの見出しの下の線は、隠れキャラの隠れ場所にもなる。

| 項目 | 中身 |
| --- | --- |
| `calls` | 応援コール `[{ title: 'コールの名前', lines: [{ who: '応援団', text: '言うこと' }] }]`。左に `who`(小さい見出し)、右に `text`。`text` は `\n` で改行できる。空白(全角・半角)で区切ったまとまり(「ま・つ・ど」など)の途中では折り返さない |
| `song` | 応援歌 `{ text: '1行' }`。コールの最後に、グレーの小さめの文字で1行だけ出る(今は「応援歌「ダイナミック琉球」でも盛り上がろう！」)。**歌詞は書かない**(市販の曲で著作権があるため。`content.js` は公開リポジトリにある) |
| `goods` | 応援グッズ `[{ name: '名前', desc: '説明' }]`。今は空 `[]` で出ない(例は `content.js` のコメント)。入れると、コールの下に「GOODS」の見出しつきで1件ずつ出る |
| `image` | 1つめのコール名の行の右に小さく飾るイラスト(`img/cheer.png`、背景が透明のPNG)。`src` を空にすると出ない |
| `sloganText` | スローガンの見出しの下の一文。`{slogan}` の所に `site.slogan` の言葉が入る(今は「今回のスローガンは『{slogan}』！」→「今回のスローガンは『一致団結』！」)。`site.slogan` が空なら一文は出ない |

スローガンのブロック:コール名と同じ見出し「スローガン」+ 黒い線 → 一文 → 画像(`site.sloganImage`)。画像は背景が白なので枠線なし、スマホは幅いっぱい・PCは幅480pxまでで左寄せ。`site.slogan` も `site.sloganImage` の `src` も空なら、ブロックごと出ない。応援歌の1行との間は、隠れキャラの吹き出しが出られるようにコールの間より広い(64px)

### おたのしみ(間違い探し) … `fun`

今は間違い探しだけ(隠れキャラはページのあちこちに隠れているだけで、おたのしみには欄を出さない)。間違い探しが空なら、おたのしみのセクションごと消えて、目次の番号が詰まる。
- 問題は紙のしおりに載っていて、サイトには答えだけ載せる
- `spotText`: 見出しの下の1行の説明
- `spotAnswerImage`: 答えの画像。「答えを見る」を押すまで出ない(もう一度押すと隠れる)
- `spotPendingText`: 答えの画像がまだ空の時に「答えを見る」を押すと出る1行(今は「答えは準備中！」)
- 説明も画像も空なら、間違い探しの欄ごと消える

### 隠れキャラ … `hiddenChars`、`hiddenCharsRandom`、`hiddenCharFrames`、`hiddenCharsDone`
- ページのあちこちにキャラが隠れて、顔だけ出している。タップすると出てきてセリフを言い、数秒で戻る。3体全部見つけると紙吹雪が出る(気づいた人へのごほうび。数やメッセージは出さない)
- 隠れ場所(`hiddenCharFrames`。今は `['cover', 'lines', 'callLines']`)
  - `'cover'`:表紙イラストの上のふちから顔を出す。**必ず1体ここに入る**(`'map'` などほかの枠の名前を書いた時も同じ)
  - `'lines'`:セクションとセクションの間の黒い線。線を地面にして、**線の下から頭だけ出す**(線より下は見えない)
  - `'callLines'`:応援コールの、各コール名の下の黒い線と、スローガンの見出しの下の線(同じ形)
  - `'nums'`:セクションの大きい番号の後ろ(前の形。今は使っていない)
- 残りのキャラは `'lines'`・`'callLines'` の線からランダムに選ぶ。1本の線に1体だけ。非表示のセクションの線・最後のセクション(下に線が無い)は外れる。線の上のどこに出るか(左寄り・真ん中・右寄り)もランダムで、線のすぐ上の文字・イラスト(コール名・「スローガン」の見出し・応援のイラスト)に重なる位置は使わない。どのキャラがどこに入るかも開くたびに変わる
- `hiddenCharsRandom: false` にすると、各キャラの `frame` / `side` / `pos` の決まった場所に隠れる(イラストの枠 `'cover'` / `'map'` と番号 `'num-1'` … だけ。線は選べない)
  - `frame`: 隠れる枠。`'cover'` 表紙イラスト / `'map'` 簡易マップ / `'num-1'` セクション番号の01
  - `side`: 顔を出す向き。`'top'` / `'left'` / `'right'`、`pos`: `'start'` / `'center'` / `'end'`
- 1体ごとに `image`(キャラの画像。空なら点線の丸)、`line`(タップした時のセリフ)、`show`(キャラの高さのどれだけを見せるか。0〜1、書かなければ `0.6`。今は3体とも「パンと目のあたりまで」見える値:1・2体目 `0.6`、目が低い3体目 `0.68`)
- `hiddenCharsDone`: 3体全部見つけた時に、最後のキャラが吹き出しで言うセリフ。今は空 `''`(ふつうのセリフのまま紙吹雪だけ)
- `hiddenChars: []` にすると、隠れキャラは出なくなる
- 見つけた状態は見た人のブラウザに「何体目か」で保存される(保存の名前は `hidden-chars-v16`。本番直前にリセットする時は、`js/main.js` の `HIDDEN_KEY` の名前を変える)。並び順を変えると保存した状態がずれるので、公開後は後ろに足すだけにするのがおすすめ
- 候補の場所がキャラの数より少ない時は、出せる数だけ出る(`?check` に出る)

### 注意事項 … `notices`
- 1件ずつ `{ text: '注意事項の文', strong: '太字にする言葉' }`。上から `01`・`02`…の番号(Oswaldの黒い数字)つきで出る
- `strong` の言葉だけ太字＋文字の下半分に薄い緑のマーカー(`text` と1文字も違えずに書く)。2か所ある時は `strong: ['1つめ', '2つめ']`。強調しない注意事項は `strong` を書かない
- **緊急連絡先は書かない**(公開サイトのため。紙のしおりだけに載せる)

### 共有時のプレビュー(OGP)とアイコン

LINEやSNSでURLを送った時のタイトル・説明・画像は、`content.js` ではなく **`index.html` の先頭(`<head>`)に直接書いてある**(LINEなどはJSを動かさずにHTMLだけ読むため)。

**体育祭の名前が変わったら**(今は仮決定の「とりかしまつり」)
1. `js/content.js` の `site.name` を書き換える(いつも通り)
2. `index.html` を開き、`<title>` と `og:title` の `content` を書き換える(`description`・`og:description` にも名前が入っている)
   - 今: `<meta property="og:title" content="とりかしまつり｜SPORTS DAY 2026 しおり">`
3. `?check` を付けて開き、「OGPのタイトルに体育祭の名前が入っていない」が出ていなければOK

**画像を差し替える時**
- 共有時の画像: `img/ogp.png` を同じ名前で上書きする(**1200×630px**、PNG、300KB以下がおすすめ。文字はスマホで小さく出ても読める大きさに)
  - 今のは、左に「11.27 FRI」「SPORTS DAY 2026」「体育祭しおり」、右に表紙のイラストの上の方を入れた画像(約126KB)。作り方は手元の `reference/ogp/`(`ogp.html` を `make.sh` で撮る。公開はしない)
- アイコン: `favicon.svg`(タブのアイコン)、`favicon-32.png`(32×32、SVGが使えないブラウザ用)、`apple-touch-icon.png`(180×180、iPhoneのホーム画面用)を同じ名前で上書きする
- LINEはプレビューを長め(数日〜)覚えているので、先にURLを送っていた場合は、差し替えてもすぐには変わらないことがある

## 2. 画像の入れ方

1. 画像ファイルを `img/` フォルダに入れる(ファイル名は半角英数字がおすすめ。例: `cover.png`)
2. `js/content.js` の該当する `src` にパスを書く: `{ src: 'img/cover.png', alt: '表紙のイラスト' }`
3. `alt` は画像が見えない人向けの説明。飾りだけなら `''` のままでいい

`src` が `''` (空)の間は、斜線の仮の枠が表示される。

| 画像 | 場所 |
| --- | --- |
| 表紙イラスト | `site.coverImage`(下の「表紙・裏表紙」) |
| 裏表紙イラスト | `site.closingImage`(下の「表紙・裏表紙」。空なら出ない) |
| 簡易マップ | `places.mapImage`(今は使っていない。入れると施設案内が復活する) |
| スローガンの画像 | `site.sloganImage`(`img/slogan.webp` 約50KB ＋ `img/slogan.jpg` 約92KB、1200×712。元は `しおり_イラストたち/スローガン/スローガン.png`(1628×966、白い背景に手書きの「一致団結」)を幅1200pxに縮めたもの)。応援コール＆スローガンの最後に出る。`alt` は「スローガン『一致団結』」 |
| 応援のイラスト | `cheer.image`(背景が透明のPNG。余白を切って高さ400px前後に。今は `img/cheer.png`、元は `しおり_イラストたち/その他挿絵/IMG_9278.png`) |
| 走るキャラ | `timetable.runnerFrames`(下の「走るキャラのコマ」) |
| 間違い探しの答え | `fun.spotAnswerImage`(横幅いっぱいに、縦横の比率はそのままで出る) |
| 隠れキャラ | `hiddenChars` の各 `image`(背景が透明のPNG。余白を切り落として高さ240px前後・50KB前後に。48px四方に入る大きさで出る。頭が上になる向きで描く。見せる量は `show`) |

### 表紙・裏表紙
```js
coverImage: { src: 'img/cover.webp', fallback: 'img/cover.jpg', width: 1200, height: 1697, alt: '体育祭の表紙イラスト' },
closingImage: { src: 'img/closing.webp', fallback: 'img/closing.jpg', width: 1200, height: 1455, alt: '一致団結' },
```
- `src` は WebP、`fallback` は WebP が見られない古いブラウザ用の予備(JPG)。どちらか片方だけでもいい(`fallback` を書かなければ `src` だけ)
- `width` / `height` は画像の大きさ(px)。**画像を差し替えたら、ここも新しい画像の大きさに直す**(絵の比率で枠の高さを決めるのと、読み込み中にレイアウトがずれないようにするため)
- 表紙:縦横の比率のまま、切り取らずに全体が出る。スマホは名前のすぐ下に幅いっぱい、PCは左の文字と横に並んで、絵の高さは560pxまで。外側に黒い1px線(隠れキャラが1体、必ずこの枠の後ろに隠れる。スマホでは名前との間を56px空けて、キャラが顔を出しても・タップで全身出ても名前にかからない)
- 裏表紙:注意事項の後、フッターの緑のストライプの上に、絵だけ出る(見出し・番号なし)。スマホは幅いっぱい、PCは真ん中に幅480pxまで。隠れキャラは隠れない。`src` を `''` にすると出ない
- 今の画像は、届いた元の絵(表紙 2480×3508、裏表紙 2480×3008)を幅1200pxに縮めたもの。元の絵は `しおり_イラストたち/` にあって、公開しない(`.gitignore` 済み)

### 走るキャラのコマ
「いまここ」のトラックを走るキャラは、何枚かのコマを順番に切り替えて、走っているように見せている。

```js
runnerFrames: ['img/runner-1.png', 'img/runner-2.png', 'img/runner-3.png', 'img/runner-4.png'],
runnerFrameMs: 330, // コマを切り替える間隔(ミリ秒)
runnerAlt: '走るはとさん',
```

- 走るのはプログラムの時間中だけ。始まる前・プログラムのすき間・全部終わった後は、2コマ目(足をそろえたコマ)で止まる(スマホの「視差効果を減らす」など、動きを減らす設定の時も2コマ目のまま)
- 高さ72pxで出る。**絵の下の端が足元**になって、トラックの緑の線の上に乗る
- コマを描き直す時は、全部のコマを**同じ大きさ・同じ範囲**で切り落とす(コマごとに切るとキャラの位置がずれてガタガタする)。背景は透明のPNG、右向き。高さ240px前後・1枚50KB以下がめやす
- 今のコマは、元の絵(870×870px)の4枚全部が入る範囲(左上 220,12 〜 右下 666,857)で切って、127×240px に縮めたもの。元の素材は `しおり_イラストたち/体育祭_しおり_走る子/` にあって、公開しない(`.gitignore` 済み)
- `runnerFrames: []` にすると、点線の丸の仮の枠に戻る

## 3. 確認のしかた

URLの最後に付けて開く。

| 付けるもの | 何が起きるか |
| --- | --- |
| `?check` | ページの一番上に「まだ［］のまま残っている項目」「画像が未設定の場所」(走るキャラのコマ `runnerFrames` が空の時、裏表紙 `site.closingImage` が空の時もここに出る。施設案内が非表示の時の簡易マップは出ない)「説明が空の競技」の一覧が出る(時刻やキャンパスの色が見つからない競技がある時は、それも出る)。全部0件になれば入れ忘れなし |
| `?time=10:30` | 11/27の10:30として表示される。「いまここ」のキャラとNOW表示の確認用(例:`?time=09:30` 始まる前、`?time=17:40` 終了後) |
| `?time=10:30&check` | 両方いっしょに使う |

例: `https://kuro-83.github.io/sports-festival-2026/?check`

どちらも付けない普段の表示には影響しない。

## ファイル構成
- `js/content.js` … **しおりの中身。ここだけ書き換える**
- `img/` … 画像を置く場所(`img/ogp.png` は共有時のプレビュー画像)
- `favicon.svg`・`favicon-32.png`・`apple-touch-icon.png` … ブラウザのタブ・ホーム画面のアイコン
- `index.html` … ページの枠
- `css/style.css` … 見た目。色・フォント・線は先頭の `:root` にまとめてある
- `js/main.js` … ページを組み立てる処理、「いまここ」、競技説明、応援コール＆スローガン、隠れキャラ、間違い探しの答え、注意事項、ハンバーガーメニュー、入れ忘れチェック
- `js/vendor/budoux/` … 日本語を文節で区切るライブラリ BudouX(v0.10.4、Google、Apache License 2.0。`LICENSE` も同じ場所)。下の「日本語の折り返し」

### 日本語の折り返し(BudouX)
- 競技説明のひとこと・ルール・見どころ・Q&A、応援コールの文、スローガンの一文、注意事項は、`js/vendor/budoux/budoux-ja.js` で文を文節に区切って、切れ目に `<wbr>` を入れている。CSS(`.phrases`)の `word-break: keep-all` で、切れ目と空白以外では折り返さない(1つの文節が1行に入らない時だけ、保険で途中でも折る)
- 外部のCDNは使わず、ファイルをリポジトリに置いている(npm の `budoux@0.10.4` の `module/parser.js` と日本語モデル `module/data/models/ja.js` を、`<script>` で読めるよう1つにまとめたもの。中身は書き換えていない)
- 折り返してほしくない空白は `\u00A0`(例:キャンパス対抗リレーのルール「3位\u00A040点」)
